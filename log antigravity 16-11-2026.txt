▸ Thought for 9s
  Sim, tem como rodar pelo Expo Go perfeitamente! Todas as dependências que usamos (react-native-webview, expo-screen-
  orientation, expo-navigation-bar, etc.) são 100% suportadas nativamente pelo Expo Go.

  Siga este passo a passo:
  ──────
  ### 1. Instalar as dependências do projeto

  No terminal, na pasta do projeto, instale as dependências (caso ainda não tenha instalado):

    npm install
  ──────
  ### 2. Iniciar o servidor do Expo

  Execute no terminal:

    npx expo start

  (ou simplesmente clique no arquivo start-all.bat)
  ──────
  ### 3. Abrir no Celular com o Expo Go

  1. Baixe o Expo Go na Google Play Store https://play.google.com/store/apps/details?id=host.exp.exponent no seu
  celular Android (ou TV Box).
  2. Certifique-se de que o celular e o computador estão na mesma rede Wi-Fi.
  3. Abra o aplicativo Expo Go no celular.
  4. Toque em "Scan QR code" e aponte a câmera para o QR Code que apareceu no terminal do seu computador.
  5. O aplicativo compilará e abrirá automaticamente em Modo Paisagem (Landscape) com toda a interface Frutiger Aero e
  os controles touch ativos!
  ──────
  │ [!TIP] Dica se o celular não conectar pelo Wi-Fi comum (Firewall / Redes Separadas)
  │ Se o seu Wi-Fi bloquear a comunicação direta entre o PC e o celular, você pode rodar o Expo pelo modo túnel da
  │ nuvem:
  │
  │   npx expo start --tunnel
  │
  │ Ele vai gerar um QR Code que funciona mesmo em redes diferentes ou até pelo 4G/5G.
